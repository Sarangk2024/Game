# Memory Card Matching Game

A responsive React memory card matching game built with Vite.

## Features

- 16-card default game with 8 matching pairs
- Random shuffle on every new game
- Two-card reveal limit with automatic flip-back for mismatches
- Move counter and timer
- Win screen with final time and total moves
- Restart game button
- Bonus difficulty levels: Easy, Medium, Hard
- Best score tracking with Local Storage
- Smooth card flip animations
- Responsive layout for desktop and mobile

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
